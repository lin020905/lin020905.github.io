# lin020905.github.io

A minimal bilingual portfolio framework for GitHub Pages.

## Preview

Open `index.html` directly in a browser. No build step or package install is required.

## Structure

- `index.html` - page markup and replaceable portfolio sections
- `styles.css` - black-and-white editorial layout and responsive styles
- `script.js` - ZH / EN language switching with `localStorage`

## Deploy

This repository is named as a GitHub Pages user site. Push changes to the `main`
branch, then enable GitHub Pages from the repository root if it is not already
enabled.

## Customize

Replace the placeholder text, project cards, and contact links with real personal
information when ready. The GitHub link is preset to
`https://github.com/lin020905`.
